# 千川视频数据拉取（三合一）

这是一个本地 Chrome 扩展。它在已登录的千川页面内部运行，不依赖 Codex 对浏览器的临时接管。

当前版本：v3.1.6。可在同一个扩展中选择“引流直播间”“挂车视频”或“乘方视频”。素材范围支持“日期内新发布素材”和“所选统计日期的全部素材”：前者按创建时间过滤，后者保留所选日期的数据指标并扫描全部素材。勾选清空筛选时，三种模式都会只点击各自数据区域中“更多筛选”工具栏的真实“清空”按钮，并以角标归零、筛选标签消失作为成功条件；不会点击标签本体，避免误展开下拉菜单。不勾选则完整沿用千川当前筛选维度。没有匹配素材时仍会生成 CSV，并在明细中写入“未抓取到数据”。扩展弹窗每次打开都会与当前千川页面核对真实运行状态，自动清除扩展重载遗留的假运行状态。三种模式均在每次运行时读取千川实际视频表头，严格按当前列名、列数量和列顺序导出。

日期区采用与千川相同的范围形式：`开始日期 ～ 结束日期`，并提供今天、昨天、最近3天、最近7天、最近15天、最近30天、上周、本月快捷项。最近 N 天按千川口径截至昨天。

导出的 CSV 第一条数据为该统计日期范围的千川原始汇总行，包含整体展现、整体消耗、成交金额、支付 ROI、净成交金额及净成交 ROI 等汇总指标；之后才是各视频明细。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择整个 `qianchuan-video-exporter` 文件夹。

## 使用

1. 登录千川，打开“全域投放 → 推直播间 → 素材 → 视频”。
2. 点击 Chrome 工具栏中的“千川近七天视频数据导出”。
3. 保持统计天数为 7，点击“开始抓取并导出 CSV”。
4. 扩展会自动关闭页面弹窗、把顶部统计日期设为“最近7天”、清空筛选、按创建时间降序、翻页读取数据并下载 CSV。

扩展会验证“清空”是否真正生效，并在读取每页前轻微移动横向滚轴，以处理千川固定列和滚动列偶尔错位的问题。

从 1.1.0 开始，单个步骤失败不会立即停止。扩展会继续执行可行步骤。诊断报告保存在扩展中，可通过“下载上次诊断报告”按钮单独下载，避免 Chrome 拦截连续自动下载。

1.2.0 会扫描全部分页，不再因为某一页出现旧日期就提前结束；同时按真实表头行保留空白复选框列，避免所有字段整体错位。

1.2.1 只使用表格“创建时间”列判断视频是否属于近七天；翻页优先点击连续页码数字（1、2、3……），运行开始时先返回第 1 页。

1.3.0 会在校准每页表格后检查创建时间边界，进入七天以前的数据即自动停止；扩展窗口也提供“停止读取并生成诊断”按钮，可随时终止翻页并保留已抓数据。

1.4.0 支持明确的开始/结束日期与可选筛选行为。未勾选“应用以下日期范围”时沿用千川当前日期；未勾选“清空当前素材筛选”时保留人工设置，包括已排除素材状态。

更新扩展文件后，请在 `chrome://extensions/` 中点击本扩展卡片上的“重新加载”，再刷新千川页面。

CSV 使用 UTF-8 BOM，可直接用 Excel 打开。统计区间按本机日期计算，7 天表示“今天及之前 6 个自然日”。

## 注意

- 千川页面更新后，如果按钮或表格结构发生变化，扩展可能需要同步更新。
- 抓取过程中请不要切换千川表格的筛选、排序或页码。
- 扩展只读取当前页面数据，不上传数据，也不会修改、删除或新建投放计划。
